## 已复现并修复

- 顶栏草稿标签的已渲染文字尺寸阻止窗口从宽布局收缩。显式保留 92 px 最小宽度，让原有省略标签可收缩；完整语义文字、提示和按钮尺寸保留。新增回归在 `Review source`、`Source changed`、`Preview unavailable` 三种状态下复现，修复后均可回到 1024×768。
- 大文件采样匹配只能证明部分内容一致，仍保留来源复核门禁；界面不再一律称为内容已变化。确实不匹配的详细原因与清除确认保持不变。
- 来源待复核时，普通追踪导出已禁用，但物理分析和 PNG 导出仍能进入选择器。现统一禁用对应按钮，并在处理入口及选择器返回后复验状态。回归覆盖直接调用和选择器期间状态变化，不写出文件。
- Review 是只读整行选择表，但原先 Tab 在单元格间移动；采用 Data 表已经使用的 `setTabKeyNavigation(False)`，正反向 Tab 离开表格，方向键仍选择行。
- `pump_until` 在一次短暂空闲后处理新事件，若后续任务随即启动就提前失败，没有继续等到期限。现继续处理到状态稳定或原期限届满；零延迟启动后续任务的回归修复前失败、修复后通过。
- 实际原片具有可变帧间隔，而旧追踪结果用 `frame_index / fps` 生成时间。5536 个唯一视频包 PTS 按呈现顺序排列后，旧时间轴最大偏差 `0.017428556358380476 s`，平均绝对偏差 `0.00681079990038871 s`。OpenCV 已提供正确的帧时间，现读取 `CAP_PROP_POS_MSEC`，在预取队列中与帧绑定，并传给线程和独立进程两条计算路径。没有时间戳的 reader 保留原 FPS 回退；声明为无效时间戳的 reader 失败而不发布该帧结果。
- UI 测试清理只处理仍可见的窗口，不再反复重绘已关闭的旧窗口。响应性测试等待“帧数与 heartbeat 均足够”，而不是帧数先满足就提前退出；原 120 ms 期限和 heartbeat 要求不变。
- 两项隔离进程测试在子进程加载整个测试模块时先导入 NumPy/OpenCV，可能在触发模拟故障前就耗尽 1 秒期限。仅将既有崩溃、阻塞及非法载荷发送器原样移至标准库支持模块 `tests/isolated_media_faults.py`；产品 IPC、防反序列化执行断言、0.8 秒响应上限及 1 秒超时均未修改。定向 13 项全部通过。
