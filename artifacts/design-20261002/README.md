## 功能位置

顶部按素材、定标、追踪、检查、信号、流程、高级排序。打开/保存/导入、运行/取消、追踪导出固定在工具带；中间分别提供实验准备、选区与定标、目标与修订、运动学与拟合、信号处理等命令。左侧只管理素材，右侧保留参数，视频和物理工作台继续使用原分隔器。1024×768 时中间命令组允许水平滚动，固定操作仍可见。

工具带对已注册动作直接使用原 QAction，不注册重复 handler；参数类命令调用原按钮，并通过公开 Qt EnabledChange/ToolTipChange 同步其状态。原控件直接归属最终父容器，没有在运行时移动已有布局中的控件。运行中的取消、来源复核导出门禁、未保存/草稿/结果替换保护没有放宽。
